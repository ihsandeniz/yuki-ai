## Nasıl çalıştırılır?

1. Yukarıdan **Yuki-0.4.0.AppImage**'ı indir.
2. Çalıştırma izni ver: `chmod +x Yuki-0.4.0.AppImage` (veya sağ tık → Özellikler → "Çalıştırılabilir").
3. Çift tıkla aç — kurulum yok.
4. **⚙ AYAR → 🔑 ANAHTAR** → [openrouter.ai/keys](https://openrouter.ai/keys) ücretsiz anahtarını yapıştır → Kaydet.
5. Yuki'yle konuşmaya başla ✨

## Gereksinimler

- Linux (x86_64), glibc tabanlı bir dağıtım
- İnternet bağlantısı (LLM için — OpenRouter API)
- Bir OpenRouter API anahtarı (ücretsiz alınır)

## Gizlilik

Anahtarın ve verilerin **yalnızca kendi bilgisayarında** saklanır (`~/.config/alice-ai/`). Uygulama, seçtiğin LLM sağlayıcı (OpenRouter) dışında hiçbir yere veri göndermez.
